# Nozomi Networks

> Nozomi Networks is an operational technology (OT), IoT and cyber-physical
> systems (CPS) security company. Its platform delivers asset visibility,
> vulnerability management and threat detection across industrial and critical
> infrastructure environments — monitoring OT/IoT/IT devices across thousands of
> installations worldwide. Core products are the Vantage cloud platform, the
> on-premises Central Management Console (CMC), and the Guardian, Guardian Air
> (wireless) and Arc (endpoint) sensors, plus Threat Intelligence and Asset
> Intelligence enhancement modules.

Note: Nozomi Networks exposes a Vantage REST API and an N2OS / Universal SDK for
programmatic integration, but the full API reference is delivered inside the
authenticated Vantage tenant and technical documentation portal — no public
OpenAPI description was found on the open web at enrichment time.

## Products
- [Vantage](https://www.nozominetworks.com/products/vantage): SaaS cloud OT/IoT security management platform.
- [Guardian](https://www.nozominetworks.com/products/guardian): Network appliance/virtual sensor for OT/IoT visibility and detection.
- [Arc](https://www.nozominetworks.com/products/arc): Endpoint sensor.
